# Antes de hacer cualquier cosa, asegúrate de tener:

- Cualquier versión de ubuntu que sea compatible con ROS2. Puedes usar [WSL](https://learn.microsoft.com/en-us/windows/wsl/install).
- Cualquier versión de [ROS2](https://docs.ros.org/en/jazzy/Installation.html) compatuble con tu versión de ubuntu.
- [Turtlesim](https://docs.ros.org/en/jazzy/Tutorials/Beginner-CLI-Tools/Introducing-Turtlesim/Introducing-Turtlesim.html).

Este último es un paquete de ROS2 que se usará para probar el código en este repositorio. Puedes instalarlo ejecutando el siguiente comando:

```bash
# instalar ROS2 y Turtlesim
sudo apt install ros-<ros-distro>-desktop
sudo apt install ros-<ros-distro>-turtlesim
```

Sin embargo, es preferible que revises la documentación, ya que el proceso de instalación puede variar según tu sistema operativo y la versión de ROS2. Además, te ayudará a comprender los conceptos básicos de ROS2 y cómo usarlo.
