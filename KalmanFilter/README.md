 # Implementación de un Filtro de Kalman en Python

 Este proyecto usa la libreria `filterpy` para implementar un Filtro de Kalman en Python. El Filtro de Kalman es un algoritmo que permite estimar el estado de un sistema dinámico a partir de mediciones ruidosas. 

 En este caso viene una simulación de un objeto que se describe con ecuaciones no lineales por lo que se usa el filtro de kalman extendido (EKF) pero cambiarlo a un sistema lineal es bastante simple. 

 Puedes experimentar con los parámetros del filtro y las mediciones para ver cómo afectan la estimación del estado. Incluso cambiar las ecuaciones del sistema para ver cómo se comporta el filtro en diferentes escenarios.
